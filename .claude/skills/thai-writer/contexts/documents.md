# สรุปประชุม คู่มือ และเอกสารทั่วไป

## หลัก

### สรุปประชุม

ขึ้นต้นด้วยข้อตัดสินใจ ผู้รับผิดชอบ และวันกำหนด คนที่ไม่ได้เข้าประชุมอ่านส่วนแรกแล้วต้องรู้ว่าตกลงอะไรกันไป และใครต้องทำอะไรเมื่อไหร่ ไม่เล่าตามลำดับเวลาว่าใครพูดอะไร ถ้ารายละเอียดการถกกันมีประโยชน์ ใส่ไว้ท้ายสุด

งานที่ยังไม่มีเจ้าของหรือยังไม่มีวันกำหนด ให้เขียนตรงๆ ว่า `ยังไม่มีผู้รับผิดชอบ` หรือ `ยังไม่กำหนดวัน` ห้ามเดาชื่อหรือวันใส่ให้ครบช่อง

```text
ตัดสินใจ
1. เลื่อนเปิดตัวแคมเปญไปวันที่ 3 ธันวาคม
2. ตัดงบโฆษณาออนไลน์ลง 20%

ต้องทำ
1. แก้แผนสื่อตามงบใหม่ (ฝน, ภายในวันศุกร์ที่ 22)
2. แจ้งเอเจนซี่เรื่องวันใหม่ (ต้น, ภายในวันพรุ่งนี้)
3. หาสถานที่จัดงานสำรอง (ยังไม่มีผู้รับผิดชอบ)
```

### คู่มือและวิธีใช้

ขั้นตอนที่ต้องทำตามลำดับเขียนเป็นรายการลำดับเลข ข้อละหนึ่งการกระทำ ขึ้นต้นด้วยกริยา ห้ามต่อขั้นตอนด้วยลูกศร เพราะผู้อ่านทำทีละขั้นและต้องรู้ว่าตัวเองอยู่ขั้นไหน ชื่อเมนูและปุ่มเขียนให้ตรงกับที่เห็นบนจอทุกตัวอักษร ถ้าขั้นไหนมีผลที่ผู้อ่านควรเห็น เช่น หน้าจอเปลี่ยน ให้บอกไว้ในขั้นนั้น จะได้รู้ว่าทำถูก

### เอกสารทั่วไป

หัวข้อ ตัวหนา และ bullet ใช้ตาม [core/formatting.md](../core/formatting.md) บันทึกภายในหน้าเดียวไม่ต้องมีหัวข้อ เอกสารที่คนจะเปิดกลับมาหาข้อมูลบางส่วนจึงค่อยแบ่งหัวข้อ

## ตัวอย่าง

สรุปประชุมที่เล่าตามลำดับเวลา

ก่อน: `ที่ประชุมได้มีการหารือเกี่ยวกับกำหนดการเปิดตัวแคมเปญ โดยคุณฝนได้นำเสนอว่าควรเลื่อนออกไป เนื่องจากงานสื่อยังไม่พร้อม หลังจากหารือกันแล้ว ที่ประชุมเห็นควรให้เลื่อนเป็นวันที่ 3 ธันวาคม โดยคุณต้นจะเป็นผู้แจ้งเอเจนซี่`

หลัง

```text
ตัดสินใจเลื่อนเปิดตัวแคมเปญเป็นวันที่ 3 ธันวาคม เพราะงานสื่อยังไม่พร้อม
ต้น แจ้งเอเจนซี่เรื่องวันใหม่ (ยังไม่กำหนดวัน)
```

ข้อตัดสินใจขึ้นมาก่อน ต้นฉบับไม่ได้บอกว่าต้นต้องแจ้งภายในเมื่อไหร่ จึงเขียนไว้ตรงๆ แทนการเดา

คู่มือที่ใช้ลูกศรแทนขั้นตอน

```text
เปิดแอป → ตั้งค่า → บัญชี → เปลี่ยนรหัสผ่าน → กรอกรหัสเดิมและรหัสใหม่ → บันทึก
```

หลัง

```text
1. เปิดแอปแล้วแตะ "ตั้งค่า"
2. เลือก "บัญชี" แล้วแตะ "เปลี่ยนรหัสผ่าน"
3. กรอกรหัสผ่านเดิมและรหัสผ่านใหม่
4. แตะ "บันทึก"
```

ลูกศรบอกลำดับได้ แต่ไม่บอกว่าแต่ละขั้นต้องแตะหรือกรอก รายการลำดับเลขบอกทั้งสองอย่าง ขั้นที่แค่เปิดเมนูต่อกันรวมไว้ในข้อเดียวได้ ไม่ต้องแยกทุกการแตะ

## เมื่อไหร่ไม่ต้องแก้

```text
ของที่ต้องเตรียมไปสัมมนา
- โน้ตบุ๊กพร้อมสายชาร์จ
- บัตรพนักงาน
- เอกสารนำเสนอที่พิมพ์แล้ว 20 ชุด
```

ไม่ต้องแก้ นี่คือรายการจริงที่คนจะเช็กทีละข้อ bullet เหมาะกว่าการเขียนเป็นย่อหน้า
