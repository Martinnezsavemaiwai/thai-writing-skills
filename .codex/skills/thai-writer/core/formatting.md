# การจัดรูปแบบ

รูปแบบต้องพอดีกับเนื้อหา ไม่ใช่นิสัยของโมเดล วัดจากว่าเนื้อหามีโครงสร้างจริงแค่ไหน และผู้อ่านจะอ่านผ่านช่องทางอะไร คำตอบสามบรรทัดที่มีหัวข้อ ตัวหนา และ bullet ครบชุด อ่านยากกว่าย่อหน้าเดียวที่เขียนดี

`[Project decision]` กฎในไฟล์นี้มาจากการตัดสินใจของโปรเจกต์ โดยใช้รายการสัญญาณใน Wikipedia: Signs of AI writing เป็นกรอบ (ดู `../../../../research/punctuation-formatting-research.md`)

## ดูช่องทางก่อน

| ช่องทาง | render Markdown? |
|---|---|
| LINE, SMS, อีเมลแบบ plain text, ช่องกรอกในฟอร์ม | ไม่ render ห้ามใช้ `**`, `#`, `---`, `- [ ]` และ `- ` นำรายการ เพราะผู้อ่านจะเห็นเครื่องหมายเหล่านี้ตรงๆ ถ้ามีหลายข้อให้ขึ้นบรรทัดใหม่แล้วใส่เลข `1.` `2.` |
| แชทกับ AI, README, เอกสารที่ render ได้ | render ได้ แต่ยังต้องพอดีกับเนื้อหา |

ถ้าไม่แน่ใจว่าข้อความจะไปอยู่ที่ไหน ให้เขียนแบบที่อ่านรู้เรื่องแม้ไม่ render คือใช้ย่อหน้าและรายการลำดับเลขธรรมดา

## ตัวหนา

ใช้ไม่เกินหนึ่งจุดต่อย่อหน้า และใช้กับสิ่งที่ผู้อ่านพลาดไม่ได้เท่านั้น เช่น วันกำหนดส่งหรือคำเตือนเรื่องเงิน ถ้าทุกประโยคมีตัวหนา ก็ไม่มีอะไรเด่นอีกต่อไป

ก่อน

```text
กรุณา**ส่งเอกสาร**ภายใน**วันศุกร์นี้** และ**แนบสำเนาบัตรประชาชน**ด้วย
```

หลัง

```text
กรุณาส่งเอกสารภายใน**วันศุกร์นี้** พร้อมแนบสำเนาบัตรประชาชน
```

## หัวข้อ

ใช้เมื่อเอกสารยาวพอที่ผู้อ่านต้องกระโดดไปหาส่วนที่ต้องการ ข้อความที่อ่านจบในครั้งเดียวไม่ต้องมีหัวข้อ หัวข้อภาษาอังกฤษไม่เขียนแบบ Title Case และหัวข้อภาษาไทยควรเป็นวลีที่บอกเนื้อหา ไม่ใช่คำเดียวลอยๆ

ก่อน

```text
## สรุปประเด็นสำคัญ
ร้านปิดวันจันทร์นี้ เปิดตามปกติวันอังคาร
```

หลัง

```text
ร้านปิดวันจันทร์นี้ เปิดตามปกติวันอังคาร
```

## Bullet

ใช้เมื่อเป็นรายการจริง เช่น ของที่ต้องเตรียม หรือขั้นตอนที่ต้องทำตามลำดับ ถ้าเนื้อหาเป็นเหตุผลที่ต่อกัน ให้เขียนเป็นย่อหน้า เพราะการตัดเป็น bullet ทำให้คำเชื่อมที่บอกความสัมพันธ์หายไป รูปแบบป้ายตัวหนาตามด้วย colon ทุกบรรทัดเป็นสัญญาณที่เห็นชัดที่สุดอย่างหนึ่ง

ก่อน

```text
**ข้อดี:** ประหยัดเวลา
**ข้อเสีย:** ต้นทุนสูง
**สรุป:** ควรทดลองก่อน
```

หลัง

```text
ประหยัดเวลาได้จริง แต่ต้นทุนสูง ควรทดลองกับทีมเล็กก่อน
```

## Emoji

emoji นำบรรทัดหรือนำหัวข้อห้ามเป็นค่าตั้งต้น ข้อยกเว้นคือโพสต์โซเชียลที่ emoji เป็นน้ำเสียงของผู้เขียนจริง ถ้าผู้เขียนใช้ emoji อยู่แล้วในต้นฉบับ ให้คงไว้ ไม่ต้องเติมและไม่ต้องลบ

ก่อน

```text
📌 ประชุมทีมวันพุธ 10 โมง
📍 ห้อง 3B
✅ เตรียมตัวเลขยอดขายเดือนนี้มาด้วย
```

หลัง

```text
ประชุมทีมวันพุธ 10 โมง ห้อง 3B ฝากเตรียมตัวเลขยอดขายเดือนนี้มาด้วยนะ
```

## คำตอบในแชท

ข้อความที่สั้นกว่าประมาณสามย่อหน้าไม่ต้องมีหัวข้อ เปิดด้วยคำตอบเลย ไม่เปิดด้วย `แน่นอน!` หรือชมว่าเป็นคำถามที่ดี และไม่ปิดด้วย `หวังว่าจะเป็นประโยชน์` หรือชวนถามต่อ ถ้าผู้ใช้ถามว่าทำได้ไหม บรรทัดแรกควรตอบว่าได้หรือไม่ได้

ก่อน

```text
แน่นอนครับ! คำถามที่ดีมาก 😊

## คำตอบ
**ได้ครับ** สามารถยกเลิกได้ภายใน 7 วัน

หวังว่าจะเป็นประโยชน์นะครับ
```

หลัง

```text
ยกเลิกได้ครับ ภายใน 7 วัน
```
